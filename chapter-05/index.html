How Machines Learn

So far we've told the robot exactly what to do. But how does it learn to do things on its own? The answer behind image recognizers, ChatGPT, and our robot's brain is one surprisingly simple idea: a network of tiny knobs that gets tuned, automatically, until its guesses match reality. In this chapter you'll build that intuition — and train a real neural network right here in your browser.

Part 1 · The Big Idea

A network is a function with knobs

A neural network is just a machine that takes numbers in and puts numbers out. Inside are thousands of little dials called weights. Training means turning those dials — automatically — until the machine's output matches examples we already know the answer to.

The training loop — the same 5 steps for every model

1 · Dataexamples of input → correct answer
→
2 · Guessrun it forward, get a prediction
→
3 · Errorhow wrong was the guess?

4 · Blamewhich knob to turn, which way?

5 · Nudgeturn each knob a little

…then repeat, thousands of times. That's it. That's all of deep learning. 🔁

Whether the model recognizes a cat, writes a sentence, or moves a robot arm, only steps 1's data changes — the loop is identical. We'll meet all three by the end of Chapter 6.
Part 2 · The Building Block

One neuron = a weighted vote

A neuron looks at its inputs, decides how much each one matters (that's the weight), adds them up with a bias, and squishes the result into a decision.

y = f( w₁·x₁ + w₂·x₂ + b ) weighted sum of inputs, then an activation f

Think of a judge scoring a science fair: creativity counts ×3, neatness ×1. The judge weights each, adds them, and gives a thumbs up or down. The activation f is that final squish — e.g. ReLU (“negatives become 0”) or sigmoid (“squish to a 0–1 probability”).

Part 3 · Measuring Wrongness

Error, a.k.a. the loss

To improve, the network needs a single number that says how wrong it is: the loss. There are two great flavors — and we'll see both again later (one for text, one for the robot).

Predicting a number → “distance” loss

If the network should output 3.0 but says 2.4, it's off by 0.6. Two common measures:

|ŷ − y| (L1)   or   ½(ŷ − y)² (squared)

This regression loss is exactly what our robot's brain will use. Keep |ŷ − y| in mind. 🤖

Picking a category → “surprise” loss

If the network must choose cat vs dog, it outputs a probability. The loss is how surprised it was by the right answer: confident-and-right = tiny loss; confident-and-wrong = huge loss.

loss = −log( probability of the correct class )

This cross-entropy is what text models use to pick the next word. 💬

Part 4 · The Math That Learns

Gradient descent: walk downhill

Picture the loss as a valley. Each weight is a position on the hillside. We want the bottom (lowest loss). How do we know which way is down? The slope.

The slope (mathematicians call it the derivative or gradient) tells us two things: which direction is downhill, and how steep. Then we take one small step that way:

new weight = old weight − learning rate × slope “slope” = how much the loss changes when you wiggle this weight

The learning rate is the step size. Too small → learning crawls. Too big → you overshoot and bounce out of the valley. Try both →

Part 5 · Sharing the Blame

Backpropagation

A big network has thousands of weights. When the final answer is wrong, which ones caused it, and how much? Backprop answers this by letting the error flow backwards through the network — from the output back to every weight.

The trick is the chain rule, which sounds fancy but just means: to see how a weight deep inside affects the final loss, multiply the slopes along the path from that weight to the output.

how weight affects loss = slope × slope × … along the path a chain of gears: a tiny turn at the end traces back through each gear

Then every weight gets its own nudge (step 4). Do this for all of them at once, and the whole network inches toward better answers.

🔎 Bonus: why do we need a hidden layer at all?

One neuron can only draw a straight boundary. Many real patterns (like the two moons above) can't be split by any single line. Stacking a hidden layer of neurons lets the network combine several bent pieces into a curvy boundary — the more neurons, the more flexible the shape. That flexibility is exactly why deep networks are so powerful.

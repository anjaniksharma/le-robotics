🎛️ Live Motor Control

Drive a real STS3215 servo straight from this page. Your slider → the Python bridge → USB → the motor. The on-screen rotor mirrors the actual encoder read back from the motor, so you can watch it chase your target — that's closed-loop control in action. No motor plugged in? It runs in simulation.

⚠️ Can't reach the bridge server. Start it first:  source .venv/bin/activate then python le-robotics/live-demo/motor_bridge.py  and open http://localhost:8777 (not the file directly).
